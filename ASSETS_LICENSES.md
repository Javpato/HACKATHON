# Asset provenance — license decision pending

All bundled visual art is drawn specifically for StudyVillage using Canvas primitives or the repository's `assets/app-icon.svg`. No assets were copied from the games mentioned as visual references. The PNG/ICO app icons are deterministic rasterizations of that SVG generated with the Tauri icon CLI.

No final project or asset license is selected. The human must decide the software and asset licenses separately before public distribution. `package.json` is private/UNLICENSED solely to prevent accidental publication; this is not a final open-source license decision.

The intended official catalog policy is free downloads with explicit provenance and compatible licensing. Community packs, a catalog and executable plugins are not implemented in this slice.
